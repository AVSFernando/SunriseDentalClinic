Help & User Guide

Step-by-step guide for new staff members

Welcome to Sunrise Dental Clinic

This Help section provides simple step-by-step instructions for new staff members to use the Sunrise Dental Clinic Management System.

1. Getting Started

  1. Open the Sunrise Dental Clinic system.
  2. Enter your username and password.
  3. Click the Login button.
  4. After successful login, the Dashboard will appear.
  5. Use the sidebar menu to access different modules.

2. Dashboard

  1. Open the Dashboard from the sidebar.
  2. View the main clinic management options.
  3. Use the quick action buttons to access important functions.
  4. Use the sidebar to move between system modules.

3. Patient Management

  1. Select Patients from the sidebar.
  2. Click Add Patient to register a new patient.
  3. Enter the patient's required details.
  4. Click Save.
  5. Use Edit to update patient information.
  6. Use Delete to remove an incorrect record.

4. Doctor Management

  1. Select Doctors from the sidebar.
  2. Click Add Doctor.
  3. Enter the doctor's details.
  4. Click Save.
  5. Use Edit to update doctor information.
  6. Use Delete when a record is no longer required.

5. Appointment Management

  1. Select Appointments.
  2. Click Add Appointment.
  3. Select the patient.
  4. Select the doctor.
  5. Select the appointment date and time.
  6. Enter the treatment and notes.
  7. Select the appointment status.
  8. Click Save Appointment.
  9. The system automatically generates an appointment number.
  10. Use the search box to find an appointment by appointment number.
  11. Use Edit or Delete when necessary.

6. Payment & Billing

  1. Select Payments from the sidebar.
  2. Click Add Payment.
  3. Select the patient and appointment.
  4. Enter the treatment cost.
  5. Enter the consultation fee.
  6. The system calculates the total amount automatically.
  7. Select the payment method.
  8. Enter the payment date and status.
  9. Click Save Payment.
  10. Click Print Bill to view and print the receipt.

7. Reports

  1. Select Reports from the sidebar.
  2. Select the required report.
  3. Review the available clinic information.
  4. Use reports to support daily clinic management.

8. Logout & Security

  1. Complete your work before leaving the system.
  2. Click Logout from the sidebar.
  3. Always log out when using a shared computer.
  4. Do not share your login password with other users.

Important Notes

  • Always enter accurate patient information.
  • Check appointment date and time before saving.
  • Verify treatment cost and consultation fee before saving a payment.
  • Check the appointment number when searching for appointments.
  • Log out after completing your work.
